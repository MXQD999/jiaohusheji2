# 指尖遇春 · 立春 / 雨水 交互科普 H5

> 以指为春：融开一片冰，落下一场雨。
> 二十四节气「春之卷」触摸科普 —— 一个可以直接在浏览器里跑起来的交互动效原型。

---

## 一、怎么打开

| 场景 | 做法 |
| --- | --- |
| **电脑** | 双击 `index.html`，用 Chrome / Edge 打开。建议窗口 1440×900 或以上。 |
| **手机** | 把整个 `zhijian-yuchun` 文件夹放到同一局域网可访问的位置（或用任意静态服务器，例如 `python -m http.server 8000` 后手机访问 `http://电脑IP:8000/zhijian-yuchun/`），再用手机浏览器打开。 |
| **投屏演示** | 打开后按 `F11` 全屏，鼠标即「手指」，冰面可直接拖动。 |

> 无构建、无依赖、无网络请求：三个文件（`index.html` / `styles.css` / `app.js`）即全部作品，离线可用。
> 字体走系统「Noto Serif SC / 思源宋体 / 宋体」回退，没有网络也不会掉版。

**演示捷径**：地址栏可直接带锚点跳到任意一屏，方便讲解时跳过前面：

```
index.html#cover          封面
index.html#awaken         冰封（触摸唤醒）
index.html#spring         春醒（冬去春来）
index.html#choice         屏风 · 择节气
index.html#lichun-3       立春，且已解 3 处（0–6 可调）
index.html#yushui-2       雨水，且已解 2 处
index.html#poster         分享海报
index.html#jingzhe        惊蛰预告
index.html#modal-1        直接打开立春第 2 条知识
```

## 二、九屏流程（对应信息架构图的五层）

```
加载 Loading → 封面 → 冰封·触摸唤醒 → 春醒·冬去春来 → 屏风·择节气
                                                        ├─ 立春 · 六雪解语 → 知识浮窗（×6）
                                                        └─ 雨水 · 六雨听春 → 知识浮窗（×6）
                                                                        ↓
                                                        分享海报 → 惊蛰预告 → 回封面
```

| # | 屏 | 交互层（反馈与动效） | 视觉层 |
| --- | --- | --- | --- |
| 1 | 加载 | 墨线 2.4s 走完自动进封面 | 白纸、竖排刊头 |
| 2 | 封面 | 「开始探索」→ 冰封；右侧目次说明全流程（回应「入口逻辑模糊」） | 竖排大字 + 淡墨山 + 日轮 + 梅枝 |
| 3 | 冰封 | **按住并左右滑动**擦霜，实时「% 已融」；停手 1.6s 回冻；擦掉 80% 自动融冰 | 冷纸底 + 冰裂纹 + 霜花 |
| 4 | 春醒 | 大字「冬去春来」淡入，底部提示向下 | 朱砂印「立春」 |
| 5 | 屏风 | 左右两扇屏风；雨水未集齐六雪时锁定（图标 +「集齐六雪 · 解锁」） | 竖排节气 + 线描（梅枝 / 鸿雁） |
| 6-7 | 立春 / 雨水 | 六片雪 / 六滴雨可点：**未读=冰蓝+金环+「点击查看」，已读=退成灰墨**；点开浮窗即计一次进度 | 右上「三 / 陆」+ 六点进度条 |
| 8 | 知识浮窗 | 占屏 70%（约 1008×630），左侧线描/朱砂印 + 右侧正文 + 引文；**点浮窗以外关闭**、Esc 关闭、「下一片雪」直接续读、复制文本 | 纸面 + 金线细框 |
| 9 | 海报 | Canvas 675×900 生成，可保存 PNG；「下回 · 惊蛰」「再逛一次」 | 竖排诗 + 十二节气印 + 朱砂大印 |

**进度与解锁链**：立春集齐 6 片雪 → 雨水解锁 → 雨水集齐 6 滴雨 → 海报解锁 → 海报页可去惊蛰预告。

## 三、可用性测试里被点名的六个问题，逐条处理

| 原问题（可用性测试） | 本作品的处理 |
| --- | --- |
| 页面命名错别字 / 歧义 | 统一为「封面 / 冰封 / 春醒 / 择节气 / 立春 / 雨水 / 海报」，页眉另有「春之卷 · 冰封」等小字定位 |
| 公告页入口逻辑模糊 | **取消独立公告屏**，把「这是什么、怎么玩」压进封面右侧目次（六行，一步一解） |
| 核心内容页无返回、易迷路 | 每屏底部常驻三格导航（立春 / 雨水 / 海报），海报页另有「归 · 立春」「归 · 封面」 |
| 圆形交互点不可点击 / 无已读态 | 未读=冰蓝高饱和 + 金环 + 文案「点击查看」；已读=降透明、转灰墨、标签常显；hover 出朱砂环 |
| 弹窗关闭不明、分享卡打断流程 | 弹窗右上 ✕、「已阅 · 收起」、点遮罩、Esc 四种关闭；分享卡独立成屏，不再覆盖弹窗 |
| 只能单向跳转 | 「下一片雪 / 下一滴雨」在浮窗内续读，底栏随时回退，hash 直达任一屏 |

## 四、设计语言

* **纸与墨**：`#F3EEE1` 宣纸、`#1E211C` 墨、`#2F4C3E` 松绿、`#C9A15C` 金、`#A63D2A` 朱砂、`#D9A79E` 樱粉、`#C9DFE4` 冰。
* **字**：标题 Noto Serif SC 700，竖排大字 62–92px（桌面）/ 38–52px（手机）；西文与数字 Cormorant Garamond 小型大写。
* **线描图**：全部为手写 SVG `symbol`（梅枝、春盘、春笋、卷册、新芽、绒花、檐雨、鸿雁），不引用任何外链图标。
* **禁忌（有意规避 AI 套路）**：不用 emoji、不用重复的等宽卡片阵列、不用紫色渐变与玻璃拟态、不加阴影按钮。
* **动效**：统一 `cubic-bezier(.22,.61,.36,1)`，600–900ms；尊重 `prefers-reduced-motion`。

## 五、响应式

* 断点 `820px`：屏风改上下堆叠、浮窗改「图在上 / 文在下」、节点标签统一到雪花正下方、隐藏目次与梅枝、底栏加安全区。
* 桌面节点 6 点散布（`POS.wide`），手机改两列三行（`POS.narrow`）+ `--node-scale:.58`，保证 390×844 不重叠、可点。
* 横屏矮屏（`max-height:520px`）另有降级字号。

```
└── tools/
    ├── shot.mjs    CDP 截图工具（真实设备尺寸，用于自查）
    ├── mobile.json 390×844 十屏任务
    ├── desk.json   1440×900 五屏任务
    └── flow.json   交互冒烟测试（融冰 / 择节气 / 开浮窗 / 续读 / 海报）
```

自查命令（Node 22+）：

```powershell
node tools/shot.mjs ..\.superdesign\shot\m tools\mobile.json
node tools/shot.mjs ..\.superdesign\shot\f tools\flow.json   # 会打印每步断言
```

最近一次冒烟测试的实测结果（`node tools/shot.mjs` 的 eval 断言）：

```
f1-melt   active=s-awaken pct=100      → 2.6s 后自动进入「春醒」
f2-spring 点「向下」 → s-choice
f3-modal  点第 1 片雪 → open=true title=东风解冻 next=shown
f4-next   点「下一片雪」→ 春盘；关闭后 read=二
f5-gate   未集齐时「雨水」不可点，CTA 显示「集齐六雪解锁」
f6-poster 集齐六雨后「继续 · 生成海报」→ s-poster，canvas 1350×1800
```

## 七、内容来源

文案取自 `12组(1).pptx`（326 份问卷、四类用户画像、四层设计目标）与《月令七十二候集解》《荆楚岁时记》等公开节气资料；用户画像中「美食 71% / 民俗 68% / 物候 62% / 诗词 45% / 农耕 38%」的兴趣排序，直接决定了立春六条知识的排布顺序（物候 → 食俗 → 民俗 → 诗词 → 农事 → 绒花）。

*本作品为交互设计作业原型，非商业发布。*
